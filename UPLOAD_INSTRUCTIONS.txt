MCLauncher 11.0 now lives in its GitHub repository.

To obtain an APK from a phone:
1. Open the repository's Actions tab.
2. Run “Build standalone MCLauncher 11 APK”.
3. Select arm64-v8a for a modern 64-bit Android device.
4. Wait for the validation and build jobs to pass.
5. Download “MCLauncher-11.0-alpha21-arm64-v8a”.
6. Extract and install “MCLauncher-11.0-alpha21-arm64-v8a.apk”.

Never treat a failed or cancelled workflow as a usable build.
