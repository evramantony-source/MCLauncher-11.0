# Build from an Android phone

1. Open the `MCLauncher-11.0` repository in GitHub.
2. Select **Actions**.
3. Open **Build standalone MCLauncher 11 APK**.
4. Select **Run workflow**.
5. Keep `arm64-v8a` for a Redmi Pad Pro or another modern 64-bit Android device.
6. Wait for both **Validate source** and **Build arm64-v8a standalone APK** to pass.
7. Download `MCLauncher-11.0-alpha21-arm64-v8a`.
8. Extract the artifact and install `MCLauncher-11.0-alpha21-arm64-v8a.apk`.

Do not install an artifact from a failed or cancelled workflow.
